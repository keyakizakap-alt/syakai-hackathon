## 評価軸を5回改訂した経緯

選抜の過程で軸そのものが5回変わった。**各改訂で首位が入れ替わっている**ので、経緯自体を判断材料として残す。

| 回 | 軸 | 結果 |
|---|---|---|
| 1 | デモ映え主軸 | 収益モデルのないリレー系が上位に残った |
| 2 | 倫理・実現可能性・ビジネス | 動員最適化系・工作検知系を倫理で失格に |
| 3 | ＋収益性・社会課題性・技術こだわり・勝率 | 「翻訳義勇軍」が首位に |
| 4 | ＋**テーマ適合ゲート** | 翻訳義勇軍が失格、「聖地の作法」が首位に |
| 5 | ＋**AI依存ゲート** | 聖地の作法はAIが装飾と判明 |

### 決定的だった2つのゲート

**テーマ適合ゲート：推しを取り除いてもプロダクトが成立するなら、それはこのテーマの案ではない。**

**AI依存ゲート：AIを取り除いても成立するなら、それはAIプロダクトではない。**

この2つを同時に通したとき、**推し活依存とAI依存がトレードオフになっている**という構造が見えた。推し活に深く食い込む案（聖地・パリティ・寄付）はAIが不要で、AIが本体の案（翻訳義勇軍）は推し活が薄い。

| 案 | 推しを外すと | AIを外すと |
|---|---|---|
| 翻訳義勇軍（多言語防災） | 普通の翻訳ツールとして成立する ❌ | 何も残らない ✅ |
| 聖地の作法 | 聖地が消える ✅ | 普通に成立する ❌ |
| 推し活パリティ / OshiAid | 成立しない ✅ | 元々AI不要 ❌ |
| **越境発信ファイアウォール + TAG BRIDGE** | **知識資産がゼロになる ✅** | **何も残らない ✅** |

両方が抜けない唯一の領域が **ファンダム語彙・規範の越境写像** だった。該当する2案（発信側＝ファイアウォール、受信側＝TAG BRIDGE）は同じ中核能力を使っており、統合できる。それが本命。

### 失格にした案と理由

**倫理ゲート**
- Counter-Signal（協調的対抗投稿）— ブリゲーディングと紙一重。プラットフォーム規約に抵触しうる
- CROSS-BORDER CAMPAIGN KIT（動員文言の最適化）— 「最も人が動く言い方」の自動生成は善意にも悪意にも等しく効く
- MOB AUDIT / Counter-Astroturf（工作検知）— 誤判定が一般ファンへの魔女狩りになる。「自陣営限定」の制約は運用で守れない
- BUDDY BORDER / Fan Consulate — 見知らぬ個人同士の対面マッチングは加害リスクを負いきれない

**実現性ゲート**
- PROXY 代打参戦 — 発想は秀逸だが代行者の信頼担保（持ち逃げ・なりすまし）を解けない
- MELTDOWN LAB — モデルの妥当性を検証する手段がなく、数字が独り歩きする
- Solidarity Seats — 興行主の協力と本人確認基盤が前提で単独では成立しない

**収益性ゼロ**
- Fandom Relay / Petition Relay / 時差作戦室 / BORDERLIGHT / HOSTAGE — デモは最高だが誰も金を払わない

## 本命：ニュアンス税関（Nuance Customs）

国境を越える言葉を、**出る側（発信前チェック）と入る側（受信フィルタ）の両方で検める**ゲート。

### 課題の語り方 — オタク語彙から始めない

初期の設計は「地雷」「解釈違い」「同担拒否」の説明が課題説明の前提になっており、**審査員がファンダム文化を知らないと刺さらない**という致命的な弱点があった。以下に組み替える。

1. 日本のコンテンツが史上最大の規模で海外に出ている（前提知識不要）
2. **機械翻訳は「感情の極性」と「警告」を構造的に壊す**（実例1つで伝わる）
3. その結果、**誤解による国際炎上**と、**警告の失効による精神的被害**が起きる

ファンダム語彙は「課題の前提」ではなく「**最も壊れやすい証拠サンプル**」として初めて登場させる。

### デモの一撃 — 説明不要な極性反転だけを使う

> 「かわいすぎて死んだ 💀」→ 機械翻訳 → *"so cute I died 💀"* → 英語圏の受信者に**脅迫**として読まれる

「しんどい＝最高」「無理＝最高」も同じ構造。**極性が180度反転する**という事実は、ファンダム文化を知らなくても3秒で理解でき、しかも面白い。「解釈違い」「同担拒否」の解説はピッチ本編から外し、質疑で聞かれたときだけ出す。

### 機能A：発信前チェック（出国審査）

一文が各言語圏でどう誤読されるかを事前に返す。**削除も通報もせず、発信者本人にだけ返す**自己認識ツール。検閲ではない。

### 機能B：受信フィルタ（入国審査）＝「トリガー警告の越境失効」

英語圏はコンテンツ警告の規範が極めて厳格、日本は「※注意書き」文化、中国語圏はまた別。**タグが翻訳されないため、警告だけが国境で失効する。** 見たくない要素を自然文で登録すると、どの言語圏の作品でも事前に遮断する。

二次創作の話をせずとも「PTSDのトリガーになる描写への警告が、言語をまたぐと消える」として成立する。快適さではなく**精神的安全**の問題として語る。

### AIが担う、規則ベースで代替できない4処理

1. **文化規範による誤読シミュレーション** — 同じ一文を JP同人圏 / EN Tumblr-AO3圏 / KRファンカフェ圏 / CN超话圏 の4ペルソナに並列で読ませ、解釈の分岐点を出す。各ペルソナのシステムプロンプトに12項目の**規範カード**を埋め込む。ここの質がプロダクトの質になり、そのまま参入障壁になる
2. **極性反転の検出** — 「しんどい」「無理」「死ぬ」「草」「💀」「I'm dead」は最上級のポジティブ。既存の翻訳エンジンが最も壊す領域。文脈上ポジティブの可能性を第一候補として検討させ、`intensity` を必ず出力させる独立ルールを置く
3. **逆翻訳による意味乖離の自己採点** — 訳文を原言語に戻して突き合わせる。単純な類似度では極性反転を見逃すため、**極性 / register（敬語・タメ口）/ 固有名詞と数値の保存 / 否定の反転**を独立に採点する多次元スコアを設計し、閾値超えは警告に昇格
4. **1対Nの条件付きタグ写像** — 「地雷」を文脈に応じて `squick` / `NOTP` / `hard no` / `menhera aesthetic` へ分岐。辞書では原理的に作れない（新語が無限に生まれ、意味が前後のタグ列に依存する）。**偽陰性が致命的**（警告の失効＝実害）なので、迷ったら必ず警告側に倒す安全側バイアスをプロンプトに明記

補助として、用語集を完全一致＋意味検索のハイブリッドで引き、ヒットした語だけを few-shot に動的注入する（全語彙をプロンプトに詰めない）。使うほど育つ資産になる。

### 技術構成

Next.js + Vercel + Claude API。**外部データ依存ゼロ**。用語集は初期200語のYAML＋全文検索で十分（ベクトルDBは48hでは過剰）。UIは既存の機械翻訳の訳と並べる比較トグルを必ず付ける。

### 収益性

- **顧客**：海外SNSを運用するIP企業（アニメ・ゲーム・音楽事務所）、ローカライズベンダー、二次創作プラットフォーム、加えて海外向け発信を行う一般企業・自治体・インバウンド事業者
- **課金**：月額シート課金＋API従量
- **払う動機**：誤訳炎上1件のリカバリコスト（謝罪・出演見送り・不買）に対して予防費は安い
- **市場の広げ方**：「**最も壊れやすいドメインから入る**」戦略。ファンダム語彙で精度が出れば一般用途は自動的にカバーできる。オタク企業限定の狭い市場ではない

### 倫理ガードレール

- 削除も通報もせず、発信者本人にだけ返す。検閲ではない
- 個人アカウントの分析・スコアリングを一切しない
- **説教しないトーン制約**：「あなたは検閲官ではなく通訳者である。相手文化を『正しい』とせず、双方の前提の違いだけを述べよ」。これを外すと上から目線の説教botになりファンから嫌われる

### 残るリスク

「LLMラッパーでは？」という批判。回答は ①4文化×12項目の規範カードという知識資産 ②逆翻訳の多次元スコアという定量ゲート ③使うほど育つ用語集 の3点。**プロンプトを見せる覚悟でピッチする。**

## 対抗：聖地の作法（Pilgrimage Pact）

AIは薄い（AI依存1）が、**社会課題の実在証明がこの中で最強**。AIを核にしない方針に切り替えるなら依然として最有力。

『THE FIRST SLAM DUNK』が韓国・台湾・中国でヒットし、江ノ電・鎌倉高校前の踏切に海外ファンが殺到。**全員が「あの1カット」と同じ構図を狙う**ため一点に凝集し、道路への飛び出し、ごみ、私有地での排泄、近隣の病院・高齢者施設への無断立ち入りが問題化した。鎌倉市は警備員を2→5名に増員し、クラウドファンディングで費用を賄っている＝**すでに支出が発生している問題**。

**越境したファンダムの熱量が、他人の家の前で物理的に暴発している**——テーマが比喩でなく現実になっている唯一の題材。

解法の思想は「立入禁止」ではなく **「推しの名を汚すな」**。裏付けはW杯スタジアム清掃で、日本のサポーターの清掃が報道されるとサウジ・モロッコ・フランスのサポーターが自発的に追随した。**規範はルールとしてではなく「かっこいい振る舞い」としてファンダム経由で国境を越える。**

技術的な山：GPS誤差前提のジオフェンス判定（都市部の測位誤差は数十m、単純な円判定では誤発火する）／バッテリーと精度のトレードオフ／分散誘導アルゴリズム（一点集中は禁止ではなく代替の提示でしか散らせない）／オフライン動作（SIMなしの訪日客が主対象）／EXIF＋perceptual hash によるチェックイン検証。

会場に仮設ジオフェンスを張り、審査員のスマホで体験させられる。リスクは作品の権利処理で、**デモは架空作品で回避する**。

## 全案に共通で入れる設計原則

複数のエージェントが独立に到達した原則。どの案を選んでも入れる。

1. **動員の目的語を「人」ではなく「締切と数値」に固定する** — 標的が個人に変わった瞬間に無血の動員は私刑になる
2. **無償で参加できる導線を必ず併設** — 課金額＝発言力という推し活の負の側面を再生産しない
3. **無償労働に依存しない** — 収益の一部を貢献者に還元する設計を最初から入れる
4. **推しの肖像・実名** — MVPは「推し名は入力のみ、肖像は非使用」で法務リスクを回避
5. **数値・制度は出典明示と「要確認」ラベル** — PPP係数、ビザ日数、手数料率は全て一次情報の確認が必要
6. **ピッチに批判レンズの警告を明記する** — 「熱量は動員力になる。ただし**その動員力の所有者はファンではない**」。推しを人質に取れる者（事務所・プラットフォーム・国家）がいつでもハンドルを奪える
