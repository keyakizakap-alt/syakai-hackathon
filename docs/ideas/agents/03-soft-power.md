# エージェント #3「パブリック・ディプロマシー戦略家」

> レンズ：国家・自治体・国際機関の視点。ソフトパワー、文化外交、シティプロモーション、国際世論形成。

## 前提となる戦略仮説

ソフトパワーの従来型（国営放送、文化センター、国費招聘）は「国家→個人」の一方向・高コスト・低信頼。一方ファンダムは既に**自発的な多言語翻訳網・自費渡航・24時間の情報拡散インフラ**を持つ。国家が数十億かけて構築するものを、ファンが無償かつ高信頼で運用している。

設計課題は「動員」ではなく **「ファンの既存行動に、公共的な意味と受け皿を後付けする」** こと。ここを外すと即プロパガンダになる。

## アイデア（各案に倫理ガードレールを1行付す）

### 1. Pilgrimage Passport（巡礼パスポート）
聖地巡礼を「非公式な市民外交ビザ」として可視化し、訪問の経済・文化インパクトを自治体とファン双方に返す。

- **無血の動員力**：年間1万人の自費巡礼者は、国費招聘1万人分の予算を国家に肩代わりしている
- **倫理ガードレール**：訪問データは個人特定不能な集計値のみ提供し、「動員数のノルマ」としての指標化を規約で禁止
- **48h MVP**：Next.js + Supabase(PostGIS)。Geolocation でチェックイン → 動的生成のデジタル記念証。自治体向けダッシュボードに国別内訳
- **デモ映え ★★★★☆**

### 2. Fandom Diplomacy Index（FDI / ファンダム外交指数）
ある作品が「どの国で、どんな文脈で語られているか」を可視化し、ソフトパワーの効き方を指標に翻訳する。

- **無血の動員力**：従来のソフトパワー測定は年1回・数千サンプル。ファンダム発話は日次・数百万サンプル。**世論の温度計を、砲艦外交ではなくファンの語彙で作る**という宣言自体がメッセージ
- **倫理ガードレール**：個人アカウント単位の分析・スコアリングは一切行わず、集計単位は「言語×時間」に固定
- **48h MVP**：**Wikipedia Pageviews API は言語版別に叩けて認証不要**＝「関心が何語圏で伸びたか」を無料・即日で出せる。YouTube コメント地域分布、Reddit API。Claude で文脈分類（憧憬/学習意欲/批判/政治利用）
- **デモ映え ★★★★★**（技術的に一番安全に「本物のデータ」でデモできる）

### 3. Sister City Fandom Match（姉妹都市マッチング）
「推しが同じ」を軸に、形骸化した姉妹都市制度を再起動させる。

- **無血の動員力**：姉妹都市は本来「戦後和解の道具」。締結ロジックを「産業が似ている」から「熱狂が重なっている」に置き換える。政治的緊張がある国同士でもファンダム層では接点が残る＝**対話チャネルの冗長化**
- **倫理ガードレール**：提携提案は両都市のファンコミュニティ代表への事前打診を必須フローとし、行政がファンの頭越しに進めることを構造的に不可能にする
- **48h MVP**：都市プロフィールをベクトル化 → pgvector で近傍探索。Claude で交流プログラム案を3本自動起草（使える体裁の企画書PDFが落ちてくると刺さる）
- **デモ映え ★★★☆☆**

### 4. Translation Corps（翻訳義勇軍 / 非戦の動員）
災害・保健・避難情報などの公共情報を、ファンダムの多言語翻訳ネットワークが即時に他言語化する。

- **無血の動員力**：**本案がテーマの本丸。** ファンサブ・翻訳勢は既に「数時間で数十言語」という、政府広報を凌駕する即応翻訳能力を実証している。平時は趣味だが有事には準・公共インフラ。**軍事動員に代わる「無血の動員」の最も直接的な形**
- **倫理ガードレール**：翻訳は二重チェック（別ボランティア＋機械翻訳の逆翻訳照合）を経てから配信。政治的メッセージ・特定国批判を含む文書は対象外
- **48h MVP**：機械翻訳で下訳 → ボランティアが差分編集 → **逆翻訳をLLMで生成し原文との意味乖離スコアが閾値超えなら配信ブロック**。Realtime で「今何人が何語を編集中」を表示
- **デモ映え ★★★★★**（審査員に実際に1文を翻訳してもらうと会場が動く）

### 5. Soft Power Ledger（ソフトパワー元帳）
ファンの推し活支出を、国家間の「非公式な文化貿易収支」として記帳する。

- **無血の動員力**：経済制裁が「金の流れを止める力」なら、ファンダムは「金の流れを自発的に作る力」。両者は同じ通貨で測れるという主張が外交の語彙を書き換える
- **倫理ガードレール**：支出額でファンをランク付け・可視化する機能は実装しない（課金額競争の煽動＝搾取に直結）
- **48h MVP**：レシート写真 → vision で品目・金額・通貨を抽出 → 国家間フローをSankeyで描画。個人には「あなたの1年間の推し活は、△△国へ◯円の文化投資でした」の年次まとめ
- **デモ映え ★★★★☆**

### 6. Counter-Astroturf Watch（偽装ファンダム検知）
「ファンダムを装った国家系の世論工作」を検知し、本物のファンコミュニティを守る。

- **無血の動員力**：**裏側からの回答。** ファンダムが動員力を持つと証明された瞬間、それは必ず国家に狙われる。動員力を語るなら、その悪用を防ぐ機能を同じテーブルに乗せる必要がある
- **倫理ガードレール**：判定結果は「疑わしい協調パターンの提示」に留め、断定・アカウント名の公開・自動通報は行わない（誤判定は一般ファンへの魔女狩りになる）
- **48h MVP**：①投稿時刻の異常な同期性 ②文面の類似度（埋め込み＋コサイン距離でテンプレ検出）③アカウント作成日の集中 の3指標 → グラフで協調クラスタをハイライト
- **デモ映え ★★★★★**

### 7. Fan Consulate（ファン領事館）
海外から来るファンのための、自治体公認の「非公式領事窓口」。

- **倫理ガードレール**：バディのマッチングは公共の場での対面を推奨し、個人連絡先の直接交換前に安全ガイドの同意を必須にする
- **48h MVP**：多言語チャット＋位置情報連動の現地ルール通知＋自治体PDFのRAG回答
- **デモ映え ★★★☆☆**

### 8. Neutral Ground（ノーマンズ・ファンダム）
外交関係が緊張している国同士のファンが、政治話題を構造的に排除した状態で交流できる、意図的に「機能が少ない」空間。

- **無血の動員力**：国交断絶時にも文化交流だけは残るという歴史的パターン（ピンポン外交）のデジタル版。**話題を制限することが交流を可能にする**という逆説を実装
- **倫理ガードレール**：「政治話題の排除」は中立ではなく一つの立場だとUI上で明示し、被害当事者の発言まで沈黙させていないか外部有識者のレビュー枠を組み込む
- **48h MVP**：投稿前にClaudeが「作品への言及か／国家・政治への言及か」を分類し、後者は本人にだけ警告（削除ではなく自己編集を促す＝検閲との差別化がデモの肝）。国旗・国名は表示せず「時差」だけを表示する
- **デモ映え ★★★★☆**

## 推し案トップ2

**1位：Translation Corps** — テーマ文への最も直球かつ反論しにくい回答。軍事動員が「若者の身体を国家が徴用する」ことなら、その対義語は「市民が自発的にスキルを差し出す」こと。ファンサブ文化はその能力が既に実在することの証拠であり、こちらが発明する必要がない。①社会課題としての切実さ（多言語防災情報は実際に人が死んでいる領域）②既存資源の再配置という設計の賢さ ③48hで完成度の高いものが作れる技術規模。

**2位：Counter-Astroturf Watch** — 全チームが「ファンダムの力は素晴らしい」方向に走るはずで、**唯一「その力が兵器化されたら」を扱う案**として際立つ。ソフトパワーの議論で最も抜けやすいのが「相手も同じ手を使う」という視点。

※ 2 の FDI は単体では分析ツール止まりだが、**4 または 6 の裏側の計測レイヤー**として組み込むと説得力が跳ね上がる。
