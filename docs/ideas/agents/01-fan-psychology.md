# エージェント #1「ファン心理・行動経済ラボ」

> レンズ：推し活の「熱量」がなぜ発生し、なぜ人を動かすのかを分解し、その心理エンジンを「国境を越える行動」に転用する。

## 前提：分解した「推し活の心理エンジン」7基

| # | エンジン | 中身 | 越境転用の勘所 |
|---|---|---|---|
| E1 | **代理達成感 / 名義献上** | 「自分の成果を推しの名前で計上する」。自分のためなら続かないことが、推しのためなら続く | 善行を「推しの実績」に変換すれば、利他が自己表現になる |
| E2 | **可視化された貢献と序列** | 貢献度ランキング、称号、認証バッジ。順位が可視化された瞬間に投下量が跳ねる | 国境を越えた行動を計上単位にすると、競争が国際協調に化ける |
| E3 | **同担コミュニティの所属圧** | 「界隈の一員である」証明欲求。ROMより供給側に回りたい | 翻訳・情報整理など越境労働はそもそもファンダムが無償でやっている |
| E4 | **変動報酬（ガチャ）とコレクション欲** | ランダム報酬＋図鑑のコンプリート圧 | 「まだ会っていない国の誰か」をコレクション対象にできる |
| E5 | **記念日ドリブンの締切効果** | 誕生日・デビュー日・カムバ。日付が決まると一気に動員がかかる | 国際デーとファンの記念日を接続する |
| E6 | **供物文化（センイル広告・フラスタ・寄付米）** | 「推しに恥をかかせない」規範による自発的支出の正当化 | 消えものへの支出を、越境インフラへの支出に振り替える |
| E7 | **布教欲 / 翻訳の利他** | 好きなものを他言語圏に届けたい欲。すでに越境している唯一の無償労働 | 同じスキルを人道情報の翻訳に流用できる |

K-POPファンダムの誕生日寄付・寄付米（fan rice）文化、BTSファン有志の One In An ARMY による短期間での大規模クラウドファンディング、日本でもJTB・NTTテクノクロス等による推し活×地域活性の実証などが報じられている。**「熱量が越境動員になる」ことは既に部分的に実証済みで、争点は「仕組み化されていない」点にある。**

## アイデア

### 1. センイル・インフラ（Saeng-il Infra）
推しの誕生日広告費を、国境の向こうに残る「実物」に変換し、その実物に推しの名前を刻んで返す。

- **解決**：センイル広告に年間数万〜数十万円を投じるファンの「1週間で消える虚しさ」と、支援先地域の資金不足
- **心理エンジン**：E6 供物文化 ＋ E1 名義献上 ＋ E5 記念日締切
- **48h MVP**：Next.js + Supabase。支援メニュー（井戸1基＝◯円、教室の壁1面＝◯円）を選び、達成率バーが誕生日に向けてカウントダウン。目玉は**「刻印プレビュー」**——現地の学校/井戸の写真に推しの名前入りプレートを合成して見せる
- **デモ映え ★★★★☆**：駅広告（1週間で剥がされる）／現地に残るプレートの対比が1枚絵で刺さる

### 2. 推し名義リーグ（Fandom Cup）
ファンダム対抗の「善行対抗戦」を国別・推し別のリアルタイム順位表にする。

- **解決**：NPO/国際機関の「単発寄付が続かない」問題。継続性をランキングという外部装置で担保
- **心理エンジン**：E2 序列と貢献競争（本命）＋ E3 所属圧
- **48h MVP**：リアルタイム順位表。アクションは寄付だけでなく**無償で積める行動**（署名、翻訳1件、クイズ受講、フードドライブ写真投稿）を全部ポイント化 → 課金格差を回避。**不正対策のAI審査**が見どころ（写真判定＋perceptual hashの重複検知）。ハンデ制（ファンダム規模で割る一人当たりスコア併記）がないと大手一強で萎える
- **デモ映え ★★★★★**：会場全員をその場でファンダムに分けて走らせるライブデモが可能

### 3. ガチャ翻訳（Gacha Honyaku）
多言語ファンダムの投稿を1件翻訳するとカードが1枚引ける、翻訳ボランティアのガチャ化。

- **解決**：ファンダム内の言語分断（誤訳とデマの拡散）
- **心理エンジン**：E4 変動報酬 ＋ E7 布教欲
- **48h MVP**：**AIは「答え」ではなく「採点者」**にするのがミソ。機械翻訳と人力訳をLLMが突き合わせ、ニュアンス差分をスコア化（スラング・敬語・文脈にボーナス）。これで「AIでいいじゃん」への回答になる
- **デモ映え ★★★★☆**

### 4. 推しの通った道（Oshi's Trail）
自分の寄付・行動が国境を越えて誰にどう届いたかを、推しのMV風タイムラインで追跡。

- **解決**：寄付の最大の離脱要因「どこへ行ったか分からない」。ファンは領収書ではなく**物語**を求めている
- **心理エンジン**：E1 代理達成感 ＋ E2 可視化
- **48h MVP**：3Dグローブ上に貢献が弧を描いて飛ぶ。支援先レポートをLLMで**推しへの報告書調の一人称ナラティブ**に再構成
- **デモ映え ★★★★★**（ただし中身が薄いと「きれいなだけ」と刺される）

### 5. 推しの母語（Oshi no Bogo）
推しの言語を学びたいファンと、日本語を学びたい在日外国人/難民背景の人をマッチングし、教え合いを「推し活」として成立させる。

- **解決**：語学支援ボランティアの人手不足と、ファンの内発的動機を等価交換。支援を「してあげる」から「交換する」に降ろすのが肝
- **48h MVP**：**AI同席型チャット**（詰まったら助け舟、話題が尽きたら推し関連トピック投下、終了後に表現カード生成）。これがないと初対面の会話は3分で死ぬ。安全設計の有無が評価を分ける
- **デモ映え ★★★☆☆**

### 6. 無血動員シミュレータ（Fandom Physics）
「あなたのファンダムが本気を出すと、48時間で世界に何が起きるか」を実データで試算。

- **解決**：ファン自身が自分たちの動員力の大きさを知らない（自己効力感の欠如）
- **48h MVP**：既知の単価データ×参加率シナリオで幅を出す。**単価の出典を必ず画面に明示する**（憶測を断定しない設計自体を機能にする）
- **デモ映え ★★★★☆**

### 7. 越境スタンプラリー『聖地交換』
各国のファンが自国の「困っている場所」を聖地として登録し合い、他国のファンが訪問・支援するとスタンプが押される。

- **解決**：支援の一方通行（先進国→途上国）が生む上下関係。全参加国が「支援される側」でも「する側」でもある構造に
- **48h MVP**：「あなたの国の聖地を1つ登録しないと、他国の聖地に行けない」という**互恵ゲート**を入れると思想が立つ
- **デモ映え ★★★★☆**

### 8. 推しへの手紙、届かない誰かへ（Letters, Rerouted）
推しに書いたファンレターの熱量そのままに、国境の向こうの誰かへ書くと往復書簡が成立する。

- **設計上の発明**：「推しへの手紙の練習」として入口の心理的ハードルを下げる
- **48h MVP**：LLMが翻訳＋**文化的ローカライズ注記**（直訳では失礼になる箇所を書き手にフィードバックしてから送る）。デモ用の模擬相手は**必ず「デモ用」と明示**（本物を装うと倫理的に一発アウト）
- **デモ映え ★★★☆☆**

## 推し案トップ2

**1位：推し名義リーグ** — ①ハッカソンで最も強いライブデモが成立する唯一の案 ②心理エンジンの中で最も再現性が高いのが「序列と貢献競争」（承認欲求や情緒は個人差が大きいが順位表は誰にでも効く）③無償アクションのポイント化で「課金力＝発言力」を回避しつつ、一人当たりスコアで小規模ファンダムも勝てる。リスクは「善行のゲーミフィケーション＝不謹慎」と刺されること。

**2位：センイル・インフラ** — ①ゼロから寄付を発生させるのではなく、既に出ている支出の行き先を変えるだけなので実現可能性の説得力が段違い ②対比がスライド1枚で伝わり、「なぜこれが必要か」の説明コストがほぼゼロ。

## 審査対策（共通）
「ファンの善意を利用して金を集める仕組みでは？」は必ず来る。(a) 無償で参加できる導線を必ず併設、(b) 資金の流れの透明性を画面に組み込む、(c) 推しの名前・肖像の扱いはMVPでは「推し名は入力のみ・肖像は非使用」で逃げる。
