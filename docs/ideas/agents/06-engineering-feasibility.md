# エージェント #6「実装現実主義エンジニア」

> レンズ：「作れるか」だけを基準にする。Next.js + TypeScript + Vercel / Claude API / 公開API無料枠を想定。48h・チーム3〜4人・デモ5分。

## 2026年の重要な地雷3つ（去年のハッカソン記事をコピペすると死ぬ）

- **DeepL API Free は2026年7月で新規購入不可**になった。新規はDeveloper/Growthプランへ誘導される（[eesel](https://www.eesel.ai/blog/deepl-pricing) / [ChatsControl](https://chatscontrol.com/blog/deepl-api-pricing-plans-limits-2026)）。→ **翻訳は Claude API に寄せるのが最も確実**
- **Spotify の `audio-features` / `related-artists` / `recommendations` は新規アプリで403**。2024/11/27以前にquota extensionを持つアプリのみ生存（[Spotify公式](https://developer.spotify.com/blog/2024-11-27-changes-to-the-web-api)）。→ **「曲の感情分析をSpotifyで」は成立しない**
- **Amadeus の Self-Service 無料枠は2026年半ばで廃止方向**（[Amadeus](https://developers.amadeus.com/pricing)）。→ **フライト系は「モックで逃げる」を初期設計に入れる**

## アイデア

### 1. Oshi Letter Bridge（推しの言葉の通訳所）
海外ファンのコメントを「直訳」ではなく「文化文脈まで翻訳」して届ける。
- **画面**：①MV URLを貼る→言語別に流れ込む「世界の声」ウォール ②原文／訳＋**文化注釈カード** ③日本語で返信→5言語同時生成＋**「この表現は◯◯圏では誤解される」警告が赤く出る**
- **技術**：YouTube `commentThreads.list` → Claude（1回のtool useでバッチ翻訳＋文化リスクフラグをJSON構造化出力）→ Edge SSE
- **難易度 低〜中 / 48h現実性 ◎（12hで動く）** — API1本＋LLM1本で外部依存が最小
- **モック**：クォータ枯渇に備え事前取得コメントJSONを同梱。「送信」は実際には送らない
- **デモ映え ★★★☆☆**

### 2. HEATMAP / 熱量の地政学
推しの「熱量」を世界地図にし、**社会アクションの動員可能量に換算**する。
- **技術**：MusicBrainz → YouTube + Bluesky → Claude で言語別・感情強度スコアリング → 言語→国のマッピングは REST Countries + Wikipedia言語版 → MapLibre + Natural Earth でコロプレス
- **難易度 中 / 48h現実性 ○** — 地図の見た目に時間を吸われる。地図担当を1人専任に
- **モック**：「言語→国」の推定は原理的に不正確なので**主要20カ国を事前計算してJSON固定**。換算係数は堂々と「仮係数」とラベル表示（誠実さがむしろ加点）
- **デモ映え ★★★★★**

### 3. Fandom Relay（ファンダム・リレー）
一つのメッセージが国から国へバケツリレーされ、各国でその国のファンが自分の言葉に訳し直して次へ渡す。
- **画面**：①日本→韓国→タイ→ブラジルと光の弧が伸びる地図 ②前の人のメッセージを受け取る→Claudeが自国語に訳す→**自分の言葉を1行足して**次へ ③「最初の一文がどう変質したか」の差分ビュー
- **技術**：Supabase(Realtime) でリレーチェーン管理 → Claude で逐次翻訳＋**変質度スコア**算出 → MapLibre arcレイヤ
- **難易度 中 / 48h現実性 ○** — Realtimeが不安ならポーリング3秒で代替
- **モック**：**事前に7カ国分のリレーをシードし、デモ中に審査員のスマホから8番目として参加してもらう。ここが最強の演出**
- **デモ映え ★★★★★**

### 4. 推し活パスポート
渡航コスト・現地マナー・禁止行為を1枚に。「ファンの越境を、無知による衝突なしに実現する」
- **技術**：Ticketmaster `countryCode` → Frankfurter為替 → Nager.Date祝日 → REST Countries → Claude で文化マナー生成 → Web Speech で音声
- **難易度 低〜中 / 48h現実性 ◎** — 全部キー1個以下のAPIで組み合わせるだけ
- **モック**：**フライト価格は必ずモック**。日本アーティストはTicketmasterに無いのでデモはK-POP/欧米アーティストで打つ
- **デモ映え ★★★☆☆**

### 5. Live Bridge（同時通訳ライブ字幕＋文化注釈オーバーレイ）
- **技術**：Web Speech API（無料）で文字起こし → 3〜5秒バッファでClaudeに投げ翻訳＋注釈抽出を1リクエストで同時実行 → SSE
- **難易度 中〜高 / 48h現実性 △〜○** — レイテンシ制御とバッファ設計が地雷。Chrome限定
- **モック**：**音声認識をライブでやらないのが安全策**。事前トランスクリプトを「タイムスタンプ通りに再生」するモードを裏に用意し、デモはそっちで打つ
- **デモ映え ★★★★☆**（動くと強いがコケると悲惨。二重化必須）

### 6. Misfire（誤訳炎上検知器）
投稿を投げると「この文はどの言語圏でどう誤読されるか」を予測し、炎上前に止める。
- **画面**：①投稿入力→「世界に出す前にチェック」 ②**リスクレーダー**（8言語圏の誤読リスク度を放射状チャート、赤い国をクリックで理由）③修正案の並列表示＋「なぜ変えたか」
- **技術**：**Claude API のみ**（翻訳→逆翻訳→意味乖離の自己評価という3段プロンプトチェーン）。逆翻訳の一部をGoogle Cloud Translationにやらせると「別エンジンでの逆翻訳」となり説得力が増す
- **難易度 低 / 48h現実性 ◎（最速。8hで動く）** — **外部データ依存ゼロ**
- **モック**：過去の実際の炎上事例3件をプリセットボタンに。**ゼロから入力させると審査員が何を打っていいか分からず滑るので、プリセット必須**
- **デモ映え ★★★★☆**

### 7. Oshi-Aid（推しの名前で、世界を動かす）
- **技術**：Wikidata で出身地・活動地 → World Bank でその国の指標 → Claude で課題提案＋多言語コピー生成 → OGP画像は `@vercel/og` で動的生成（**これは絶対にやるべき**）
- **モック**：**決済は絶対に実装しない**（Stripeテストモードでも48hでは事故る）。「寄付する」は実在URLへの外部リンク＋自前カウンターのみ
- **デモ映え ★★★★☆**

### 8. Setlist Diplomacy（国境なきセットリスト）
- **難易度 中〜高 / 48h現実性 △** — **Spotify OAuth のリダイレクトURI設定＋ユーザー承認フローが48hで一番の時間泥棒**。`audio-features`は使えないので「音楽的分析」は諦めLLMの知識で語らせる
- **モック**：プレイリストは開発者自身のアカウントで事前に1本作り、デモではボタン押下→埋め込みプレイヤーが出るだけに
- **デモ映え ★★★★☆**

## 結論：48hで最も確実に完成し、かつ刺さるトップ2

**1位：Fandom Relay** — 外部API依存が Claude + Supabase の2つだけ。バックエンドはテーブル1つ。コア機能12h。テーマへの回答が**画面上で物理的に起きる**（動員を語るのではなく、動員が目の前で1ホップ増える）。決め手は**審査員のスマホをリレーの次のホップにすること**。

**2位：Misfire** — **最速。外部データソースゼロ、Claude APIのみ。8hで動く**。1位案の保険として並行着手できる唯一の案。「ファンダムの熱量は、国境で誤訳に変わって暴力になる」という**負の側面**を扱う唯一の案で、他チームと被らない。リスクはほぼ無し。

**推奨進行**：初日午前に **Misfire を8hで完成させて「完成品を確保」** → 残り40hを **Fandom Relay** に全投入。デモはRelayをメインに、Misfireを「もう一つ作りました」で出せば実装力の評価も同時に取れる。
