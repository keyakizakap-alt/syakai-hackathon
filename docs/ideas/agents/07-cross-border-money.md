# エージェント #7「越境マネー・エコノミスト」

> レンズ：お金の流れ。推し活は巨額が動く経済圏だが、国境を越えると摩擦だらけ。

※本レポート中のプラットフォーム手数料率、各国の少額輸入免税ライン、PPP係数、最低賃金はいずれも概算であり、実装前に一次情報での **要確認** が必須。

## 前半：越境推し活の「お金の摩擦」8つ

**F1. スパチャ／投げ銭の三重取り構造** — プラットフォーム手数料（30%前後と言われる／要確認）＋国際取引手数料＋事務所取り分。ファンが1000円投げても推しに届くのは数百円で、しかも**ファン側からは何%届いたか一切見えない**。

**F2. 為替と可処分所得の非対称（＝推し活パリティ問題）** — 同じ「5000円のチェキ会」が、日本のファンには半日分のバイト代、東南アジア・南米・東欧のファンには数日分の生活費。名目価格は世界共通なのに痛みは10倍以上違う。**結果、熱量ではなく国籍で序列が決まる**。

**F3. 決済レールの断絶（そもそも払えない）** — 海外発行カードが弾かれる、3Dセキュア、コンビニ払い前提、ローカルウォレット限定。「金はあるのに払わせてもらえない」層が大量に発生し代行業者に流れる。

**F4. 代行・代購レイヤーの不透明マージン** — 「商品代＋代行手数料＋国際送料＋為替スプレッド＋関税立替」が一体で提示され内訳が見えない。ここに二重為替（レート盛り）が埋まる。個人代行はエスクローもなく持ち逃げリスク常設。

**F5. 関税・輸入消費税の突然死** — 到着時に予期せぬ請求→受取拒否→返送→全損。少額輸入免税ラインは国ごとに全く違う（日本1万円以下、EU IOSS 150ユーロ、米 de minimis 800ドルなどと言われるが改定が激しく **要確認**）。

**F6. チケットのジオブロックとダフ屋の裁定利益** — 「国内在住者限定」「国内発行カード限定」で海外ファンは正規ルートから排除される一方、転売業者は現地口座を持つので参入できる。**排除された需要がそのまま転売プレミアムに変換される**。

**F7. 越境クラウドファンディング／ファン募金の着地不能** — 集金は特定国のプラットフォーム限定、送金は高手数料、「集めた金がちゃんと使われたか」の証跡が主催者のスクショ頼み。持ち逃げと疑惑合戦が常態化。

**F8. 還元の可視性ゼロ** — ファンは「推しへの貢献度」で行動するのに、実際の還元率も自分の支出がどう効いたかも見えない。だから「数字が見える」課金（再生数・売上ランキング）に過剰集中し、金額のインフレ競争になる。

## 後半：アイデア

### 1. OshiPPP（推し活パリティ計算機／Fair-Share Tip）
投げ銭額を「支払う痛み」で揃える。購買力平価×最低賃金で国ごとの"等痛額"を提示。
- **誰の損→誰の得**：低所得国ファンの「参加できない／無理して破産する」損 → 堂々と参加できる正当性。推し側は課金者の裾野が広がる。日本ファンの「自分だけ金額で殴っている」罪悪感も解消
- **ビジネスモデル**：プラットフォーム／事務所へのSDK提供（導入費＋GMVの0.5%）。**ファンからは取らない**
- **48h MVP**：世界銀行PPP・各国最低賃金の静的JSON（出典明記、**要確認**）を同梱。「日本の¥1,000 = ブラジルでの労働時間換算 X 分」を提示。「等痛モード」トグル付き投げ銭ウィジェット（決済モック）。**ランキングを金額順ではなく"労働時間順"で表示するリーダーボードが目玉**
- **デモ映え ★★★★★**（「月給の3%を投げた韓国の学生」が「小遣いの0.1%を投げた日本人」より上位に来る画は一撃）

### 2. ClearRoute（代行・代購のガラス張りエスクロー）
総額を「商品代／代行料／送料／為替差／関税見込み」に強制分解し、着荷までエスクロー。
- **誰の損→誰の得**：海外ファンの「ぼったくり＋持ち逃げ＋関税不意打ち」損 → 個人代行者（多くは学生・主婦）の「信用がないから安く買い叩かれる」問題も同時に解消
- **ビジネスモデル**：エスクロー手数料1.5〜2%を折半。信用スコア上位者は減免
- **48h MVP**：内訳5項目の入力を必須化（**合計しか出せないUIを禁止**）。為替は公開APIのミッドレートを取り、代行者提示レートとの乖離を**「隠れスプレッド ◯%」と赤字表示**
- **デモ映え ★★★★☆**

### 3. Passthrough（推しへの到達率レシート）
支出を入力すると「推しに実際いくら届いたか」を推定しレシート化。
- **誰の損→誰の得**：ファンの「善意が中抜きされている無自覚」損 → 到達率の高いルート（直販、本人運営EC、ライブ物販）へ支出が移動しクリエイター本人の得に変わる。**プラットフォーム間の還元率競争を誘発**
- **ビジネスモデル**：個人無料、クリエイター／事務所向けに「うちは到達率78%」を証明する検証バッジを有料提供。長期的には到達率データ自体がメディア価値になる
- **48h MVP**：公開手数料率をコミュニティ編集可能なYAMLで管理（全て「要確認」明記＋出典リンク必須）。**Sankeyダイアグラム**で「あなたの¥10,000 → プラットフォーム¥3,000 → 決済¥300 → 事務所¥4,200 → 推し¥2,500」。年間集計で「今年あなたは中間に◯円払った」
- **デモ映え ★★★★★**（炎上力＝拡散力）

### 4. Solidarity Seats（越境チケット互助・非転売マーケット）
「行けなくなった枠」と「地域制限で買えない海外ファン」を、定価固定＋抽選＋本人確認で結ぶ利益ゼロの譲渡レイヤー。
- **ビジネスモデル**：定価超過を一切認めず「定価＋固定手数料300円」。または興行主からのライセンス（公式リセール機能として導入）
- **48h MVP**：定価上限をハードコードで強制（超過入力不可）。譲渡は先着ではなく**抽選＋熱量スコア**で配分。海外ファンには「現地サポーター」を紐付ける二人一組フロー。地図上に「この公演にどこの国から手が挙がっているか」をリアルタイム表示
- **デモ映え ★★★★☆**

### 5. Oshi Fund（推し名義の越境ファン基金／全額追跡型）
- **誰の損→誰の得**：主催ファンの「持ち逃げ疑惑をかけられる」損と参加者の「本当に届いたか分からない」損 → 双方が証跡を得る
- **ビジネスモデル**：1〜2%を運営費（明示）。企業CSRやNGOからの掲載費。各国の寄付控除対応は **要確認**、MVPでは触れない
- **48h MVP**：タイムライン形式の透明台帳（入金・両替・送金・受領書アップロード）。**全イベントは追記のみのログ（ハッシュチェーンで改ざん検知、ブロックチェーン不要）**。「あなたの¥500がこの井戸のこのタイルになりました」
- **デモ映え ★★★★☆**

### 6. Pay-Any-Way（推し活決済のラストワンマイル・ルーター）
現地の支払い手段を入口に、加盟店には国内決済として着地させる。
- **誰の損→誰の得**：決済レールから排除されたファンの「金があるのに払えない」損 → 販売側の取りこぼし解消（海外売上は"存在しなかった需要"として計上すらされていない）
- **ビジネスモデル**：決済手数料（加盟店側 2.5〜3%）。**ここは唯一「真っ当に儲かる」案**
- **48h MVP**：モック決済ルーター。実装の肝は **「なぜこのカードは弾かれたか」の説明レイヤー**（3Dセキュア未対応、発行国ブロック、AVS不一致をファンに分かる言葉で返す）
- **デモ映え ★★☆☆☆**（社会的インパクトは最大級だが決済モックだと画面は地味）

### 7. Heat Index（ファンダム熱量の越境インデックス）
「どの国にどれだけの未回収需要があるか」を可視化して興行判断とローカル価格に直結させる。
- **ビジネスモデル**：B2B SaaS（レーベル、興行主、配信プラットフォーム）。ファンからは無料でデータ提供＝自国への投票行為として設計
- **48h MVP**：ファン側は「私の国に来て」ボタン＋**等痛価格での支払い意思額**（案1と接続）。管理側は国別ヒートマップ＋「この都市で◯人 × 平均支払い意思額 = 推定回収額」。**「需要はあるが公演がない都市」を赤でランキング**
- **デモ映え ★★★★☆**

## 推し案トップ2

**1位：OshiPPP（推し活パリティ）** — テーマへの**最も鋭い一撃**。現状のファンダム経済は「熱量」ではなく「所得」を測っている。金額順リーダーボードを**労働時間順**に置き換えるという一点だけで、誰が本当に献身しているかの序列がひっくり返る。デモの言語がいらない（数字と順位だけで伝わる＝国際審査でも強い）。48hで確実に完成し、他の6案すべてに部品として組み込める基盤レイヤーでもある。弱点はPPPデータの妥当性なので、出典と「要確認」を潔く画面に出して**「議論を起こす計算式」として提示するのが正解**。

**2位：Passthrough（到達率レシート）** — **怒りを設計に変換する**プロダクト。最も知りたくて最も知らされていない「私の金は推しに届いたのか」に初めて数字で答える。Sankey図と年間サマリーはSNS拡散が確実に起き、**拡散がそのままデータ収集（手数料率のクラウドソース）になる自己増殖構造**を持つ。48hで作れる範囲も明確（計算とビジュアライズだけ、決済不要）。到達率のベンチマークを握った者が業界の還元率競争のレフェリーになれる。

**補足**：優勝を狙うなら 1 と 3 を統合（「あなたの痛みで測り、届いた額で報いる」）するのが最も筋がいい。6（Pay-Any-Way）は社会的価値が一番高いが48hのデモ映えでは不利なので今回は見送り推奨。
