# エージェント #8「人道・共生セクター担当」

> レンズ：国境が生む最もシリアスな問題群。難民・避難民、移民の孤立、分断された家族、関心の風化。
> **当事者を「エモい素材」として消費する危険を各案で意識し、尊厳を守る設計を1行添える。**

## 1. #WeStillCare（まだ、推してる）
ニュースの「関心の減衰カーブ」を可視化し、風化に抗う継続をファンダムの連続記録（ストリーク）文化で支える。

- **困りごと**：紛争地・被災地の当事者と現地NGO。報道が消えると寄付とボランティアが同時に消え、**支援が本当に必要な「復興3ヶ月後〜3年後」に資源が枯渇する**
- **熱量の転用**：推し活の中核は「一過性の爆発」ではなく「毎日の積み上げ」。ユーザーは地域を1つ「担当」し、週1回の現地発信を読むだけでストリークが伸びる。ダッシュボードには**「世界の関心量」の減衰カーブと自分たちの関心量が重ねて描かれ、"世界が忘れても私たちは覚えている"というギャップ自体が可視化される**
- **尊厳を守る設計**：関心量のグラフに使うのは報道・検索の統計データのみで、被災者個人の写真や悲惨さの度合いは一切ランキング指標にしない
- **48h MVP**：GDELT API または NewsAPI で地域別記事数を日次集計 → Recharts で減衰カーブ。Claude で現地一次ソースの3行要約（**出典リンク必須の制約付き**）。Vercel Cron で日次バッチ
- **デモ映え ★★★★★**（減衰カーブが落ちていく中で自分の線だけ横ばい、という一枚絵が強い）

## 2. ディアスポラ・デビュー
難民・移民のアーティスト／職人を「支援対象」ではなく**「推される才能」**として売り出す。

- **困りごと**：第三国定住した難民のクリエイター。母国での実績・学歴が通用せず、履歴書の空白と在留資格の壁で単純労働に固定される。**「かわいそうな人」としての物語しか売れない**
- **熱量の転用**：ファンダムは「無名の才能を見つけて育てた」という発掘者の誇りで動く。デビュー前から応援する「初期担」文化、ファンによる海外拡散、リリース日の同時購入文化を転用。ファンには「初日から推してた」という参加証（発行順ナンバー付き）が残る
- **尊厳を守る設計**：プロフィール上段は必ず作品と技能で、被災・逃避の経緯は本人が任意で書く下段の「本人が語りたい範囲」欄に限定し、非公開のままでも出品できる
- **48h MVP**：Supabase Storage + Stripe Checkout（テスト）。作者は母語で書き、閲覧者の言語で表示、**原文も常時併記**。「初期担バッジ」は購入順のDBカラムのみ
- **デモ映え ★★★★☆**

## 3. クラシ攻略Wiki
ファンダムの異常な情報整理能力（Wiki・まとめ文化）を、在日外国人の生活手続きに丸ごと転用する。

- **困りごと**：在日外国人・技能実習生・留学生。ゴミの分別、国保、住民税、賃貸契約、就学手続きが自治体ごとにバラバラで、公式情報は「やさしい日本語」ですらない。頼れるのは同国人コミュニティの口伝のみで誤情報も混ざる
- **熱量の転用**：オタクWikiは報酬ゼロで誰かが必ずテンプレを整備し初心者向けFAQを書く。この**「編集者の名誉」駆動**を移植。日本人ユーザーは翻訳・出典付けで、外国人ユーザーは「実際に窓口でこう言われた」という体験知で貢献し、**両者が同じスコアボードに乗る**
- **尊厳を守る設計**：投稿は匿名・ハンドルのみで可能とし、**在留資格や国籍の入力欄を設けない**（入管に照会されうる属性は最初から持たない）
- **48h MVP**：記事はMarkdown、履歴テーブルで版管理。Claude で記事単位の自動翻訳＋人力修正フラグ。「やさしい日本語」変換もLLMで一発。自治体データは数件手動シードで十分
- **デモ映え ★★★☆**（地味だが実用性で刺さる。攻略率ヒートマップを地図に載せると映える）

## 4. 越境ファンレター
分断された家族の間で、音声メッセージを「ファンレター」の作法で届けるリレー便。

- **困りごと**：紛争や入管収容、出稼ぎで引き裂かれた家族。通信インフラ、識字、検閲、そして**「何を話せばいいか分からない」という心理的断絶**で連絡が途絶える
- **熱量の転用**：ファンレターは「返事が来ないかもしれない相手に、それでも書き続ける」という世界一成熟した一方通行コミュニケーション文化を持つ。**「近況を聞くのではなく、自分の日常を差し出す」というファンレターの鉄則が、実は当事者の負担を減らす**
- **尊厳を守る設計**：手紙の中身は運営もAIも学習・公開に使わず、公開されるのは本人が明示的に「公開可」を押した抜粋のみ
- **48h MVP**：PWA（オフライン録音→再接続時に同期）。MediaRecorder → Whisper で文字起こし → Claude で翻訳し、**音声＋原文＋訳文の3点セット**で届ける。低帯域向けにOpus圧縮
- **デモ映え ★★★☆**

## 5. 推し記者（ローカル・オシ）
国や紛争を推すのではなく、**その土地で発信し続ける市民ジャーナリスト個人を「推す」**ことで、遠い国のニュースを継続視聴に変える。

- **困りごと**：現地のローカルメディアと市民記者。国際報道は大手が撤収すると途絶え、彼らは無収入で発信を続ける。日本の視聴者には「どこの国か分からないニュース」のまま流れ去る
- **熱量の転用**：**人は「イシュー」には飽きるが「人」には飽きない**。推し追跡（新着通知、過去投稿の遡り、月額サポート、同担コミュニティ）を個人記者に適用。ユーザーは3人まで「担当」を持つ。継続すると「〇〇さんを14ヶ月追ってる」という履歴が残り、これが風化への最大の抵抗になる。**国名ではなく顔と名前で覚えるため、ニュースが「他人事」から「知り合いの近況」に変わる**
- **尊厳を守る設計**：記者側が自分の露出範囲（顔出し／地名精度／配信遅延）を自分で設定でき、安全上の理由でいつでも即時に全公開を停止できるキルスイッチを持つ
- **48h MVP**：記者のRSS／Mastodon／YouTubeフィードを取り込む。Claude で「日本の読者が知らない前提知識」を毎記事に自動注釈。Web Push、担当期間カウンタ
- **デモ映え ★★★★☆**

## 6. 同担パス
「同じ推しがいる」だけを鍵にして、外国人労働者・留学生と地域住民をつなぐ超低ハードルのマッチング。

- **困りごと**：技能実習生・特定技能・留学生の社会的孤立。職場と寮の往復で知り合いがゼロ、体調不良や労働トラブルの相談先がない。**国際交流イベントは"支援する側／される側"の構図が固定され、誰も対等になれない**
- **熱量の転用**：アニメ・K-POP・ゲーム・サッカーは、すでに国境を越えて成立している唯一の共通言語であり、しかも**「教える／教わる」の上下がない**。同担同士は初対面でも3時間喋れる。まず「一緒に配信を観る」だけを設計し、生活相談窓口は交流の中で"ついでに"提示され、支援が前面に出ない
- **尊厳を守る設計**：プロフィール必須項目は推しと最寄り駅のみで、**国籍・在留資格・勤務先は入力欄自体を作らない**（＝支援対象としてラベリングされない）
- **48h MVP**：推しデータは Spotify Search / AniList GraphQL で正規化。マッチ後はチャットに Claude のリアルタイム翻訳を挟む
- **デモ映え ★★★★☆**（2画面を並べて別言語で会話が成立する絵が分かりやすい）

## 7. 記憶の聖地巡礼
「聖地巡礼」の作法で、失われた街を歩く。紛争前の街並みを住民自身の記憶で復元する。

- **困りごと**：故郷を破壊された避難民とその第二世代。帰れないだけでなく街の記憶そのものが失われ、子どもは親の故郷を知らないまま育つ。外部の人間には「瓦礫の映像」以上の像を結ばず数年で忘れられる
- **熱量の転用**：オタクは作品の舞台を執念で特定し、写真を撮り、地図にピンを立て、Wikiに記録する。この**「土地への偏執的な愛着と記録欲」**を、当事者の証言による街の復元に使う。避難民が地図上に「ここにパン屋があった」とピンを立て、外部ユーザーはそのピンを一つずつ「巡礼」する
- **尊厳を守る設計**：登録するのは「失われた悲惨さ」ではなく**「そこにあった日常」**に限定し、投稿ガイドで暴力描写と遺体・被害の写真を明示的に排除する
- **48h MVP**：MapLibre + OSM ＋ Supabase（ピン＝緯度経度／音声／テキスト／年代）。Whisper で文字起こし＋Claude で多言語化。1都市・ピン30件をシードで作り込む
- **デモ映え ★★★★★**（地図が証言のピンで埋まっていくタイムラプスが圧倒的）

## 推し案トップ2

**1位：#WeStillCare** — テーマへの回答として最も正面から刺さる。**ファンダムが他のどんな集団より優れているのは「熱量の大きさ」ではなく「熱量の減衰の遅さ」**であり、人道課題の最大の敵はまさに減衰（風化）だ。つまり課題とソリューションの噛み合わせが概念レベルで一致している。しかも当事者を一切素材化せずに成立する数少ない設計で（扱うのは報道統計と一次ソースへの導線だけ）、倫理的な地雷が最も少ない。48hでもデータソースが公開APIで揃い、「世界の関心が落ちる線／自分たちの線」という一枚の絵で一撃で伝わる。

**2位：推し記者** — 1位が「集団の継続」を可視化するのに対し、こちらは風化に効く**メカニズム**を提示している。**イシューは飽きるが人は飽きない**、という推し活の本質的な洞察を国際報道の持続性問題にぶつけている。さらに「支援する／される」ではなく「推す／推される」の関係に置き換えることで、**当事者を憐れみの対象にしないという本テーマ最大の倫理的難所を、設計そのもので回避できている**。1位とはデータ層と人物層で補完関係にあり、統合も現実的。

**補足**：案6「同担パス」は社会実装の即効性では最有力（日本国内で今すぐ使える）だが、ハッカソンの物語としては上位2案の方が「熱量の転用」という主題を鋭く体現している。
