# エージェント #5「非暴力動員デザイナー」

> レンズ：「無血の動員力」を社会運動論として正面から扱う。非暴力抵抗、オンライン連帯、ハッシュタグ運動、ボイコット/バイコット。

## 前半：「ファンダム型動員」が成立する5条件

実例（K-POPファンダムのBLM寄付リレー、Dallas通報アプリへの動画フラッド、ミルクティー同盟、タイの三本指、クラウド翻訳、投票喚起、バイコット消費）を分解すると共通して次の5つが揃う。逆に1つでも欠けると熱量は動員に変換されない。

### C1. 焦点（Focus）— 旗印が「人格化」されている
政策やイシューではなく「推し」という顔が旗印になることで、抽象的な大義が身体感覚のある忠誠に変換される。動員の目的語は制度でも、**動員の主語は常に「〇〇（推し）のファンとして」**。
→ プロダクトは「イシューへの参加」ではなく「推しの名義での参加」としてUIを組む。

### C2. 作法（Repertoire）— 既に訓練済みの行動文法をそのまま転用できる
ファンダムはすでに「大量投票」「ストリーミング周回」「ハッシュタグ一斉打ち」「翻訳して広める」「共同募金で広告を出す」という高度に反復可能な集合行動プロトコルを持つ。政治的動員が成功したのは新しい行動を教えたからではなく、**既存の作法の出力先を差し替えただけ**だったから。
→ 新しい操作を1つも発明しない。既存のファン行動のリスキンに徹する。

### C3. 計器（Scoreboard）— 集合的達成が即時に数値で返る
個人の微小な貢献が全体メーターを動かす瞬間の可視化が、動員の燃料そのもの。ファンダムは「数字を積む」ことに世界で最も習熟した集団。
→ メーター、カウントアップ、達成証明のシェア画像は機能ではなくコア。

### C4. 橋（Bridge）— 言語・時差・プラットフォームを越える中継層がある
国境を越える動員は必ず「翻訳する人」「時差を埋めてバトンを渡す人」が支えている。ミルクティー同盟はミームという「翻訳不要の共通語」で橋を架けた。
→ 翻訳と時差リレーを裏方タスクではなく、可視化された「役割」として与える。

### C5. 制動（Brake）— 「推しの名を汚さない」という評判ステークが効き、標的が"人"でなく"締切"である
**最重要かつ最も見落とされる条件。** 健全に機能したケースは共通して、(a) 行動の結果が推しの評判に返る構造があり自己規律が働いた、(b) 敵の個人を叩くのではなく「期日までに目標数を積む」という締切駆動だった。逆に暴走した動員は、標的が個人（晒し・大量通報・私刑）に変わり、評判ステークが「敵を倒した戦果」に置き換わった瞬間に発生している。
→ **動員の目的語を常に「人」ではなく「締切と数値」に固定する。これが全案共通の暴走防止の背骨。**

## 後半：アイデア

### 1. Bias Fund（バイアス・ファンド）
推しの名義で束ねる、国境を越えた少額寄付リレー。
- **動員したい行動**：1人300円〜の寄付を推し名義プールに（誕生日・カムバ日に合わせて）
- **メカニズム**：C1×C3。「〇〇ファンダム名義」でしか寄付できない。達成時は推しカラーの寄付証明カードを自動生成しシェア
- **暴走防止**：送金先は既存の公的NPO/NGO登録DBにあるホワイトリスト法人のみで、政党・政治団体・個人アカウントへは構造上一円も送れない
- **デモ映え ★★★★☆**

### 2. Subs for Rights（サブス・フォー・ライツ）
ファンサブ文化を転用した、一次情報のクラウド多言語化。
- **動員したい行動**：1人1文だけ翻訳する
- **メカニズム**：C2×C4。LLM下訳を叩き台として出し、人間は修正だけ。1文単位なので参加コストがツイート1回分
- **暴走防止**：氏名・顔・位置情報など個人特定要素は投入時に自動マスキングされ、かつ**異なる2名以上の相互レビューを通過しない限り公開されない**（誤訳による扇動と現地の人の身元露出を同時に防ぐ）
- **48h MVP**：Whisper + Claude下訳 + セグメント単位の差分レビューUI + PII検出（正規表現＋LLM分類の二段）
- **デモ映え ★★★★☆**

### 3. Comeback to the Polls
推しのスケジュールカレンダーに、選挙と議会日程を"同じ重み"で差し込む。
- **メカニズム**：C1×C2。ファンは既に「カムバ日・投票期間・チケット先行日」を分刻みで管理する習慣を持つ。その管理対象に公職選挙の日程を混ぜるだけ。海外在住ファン向けには在外投票の登録期限を優先表示
- **暴走防止**：候補者・政党・争点に関する推薦や評価は一切表示せず、「日程・場所・必要書類・締切」だけを扱う
- **デモ映え ★★★☆☆**

### 4. Fan Cart（ファン・カート）
不買ではなく「買って支える」だけを扱うバイコット専用アプリ。
- **メカニズム**：C2×C3。「推しのCM商品を買う」既存行動に、第三者認証（フェアトレード、人権デューデリ開示等）のレイヤーを重ねる
- **暴走防止**：ボイコット対象リスト・低評価ランキング・企業名の名指し批判機能を一切実装せず、**"買う対象"のみを扱う**（不買運動特有の私刑化・誤爆を構造的に不可能にする）
- **デモ映え ★★★☆☆**

### 5. Petition Relay（ペティション・リレー）
署名が地球を1周する様子を、タイムゾーンをまたぐバトンとして可視化する。
- **動員したい行動**：署名する＋自分の言語圏の同担に「バトンを渡す」（自分が寝ている間、次のタイムゾーンが走る）
- **メカニズム**：C3×C4の純粋形。3D地球儀の上を署名が時差に沿って光の帯として動く。ファンダムのグローバル・トレンド企画と完全に同じ体験文法
- **暴走防止**：宛先は公的機関の正式な請願窓口のみに限定し、**目標数に達した時点で自動クローズして「終わり」を作る**（終わらない動員＝暴走の温床を断つ）
- **48h MVP**：globe.gl + Supabase Realtime。シードで擬似署名10万件を流し込むと初見のインパクトが最大化
- **デモ映え ★★★★★**

### 6. Heat Guard（ヒートガード）
「その動員、いま暴走しかけている」を測る、ファンダム自身のための温度計。
- **動員したい行動**：大型アカウント運営者・企画主催者が自主的にクールダウン宣言を出す
- **メカニズム**：C5を単独プロダクト化。ハッシュタグ単位で (a)攻撃性の比率 (b)個人特定情報を含む投稿の比率 (c)投稿速度の急加速 を時系列表示。閾値超過で「今は数字を積む時間ではありません」という中立的なクールダウン文面を提示
- **暴走防止**：個別アカウント名・投稿は一切表示せず集計値のみを返す（このツール自体が晒しの道具に転用されることを防ぐ）
- **デモ映え ★★★★☆**

### 7. Encore（アンコール）
「あの署名、あの寄付は、その後どうなったのか」を90日後に推しコンテンツの形で返す。
- **メカニズム**：C3の時間軸拡張。「カムバまであと◯日」のカウントダウン文化を「請願の回答期限まであと◯日」に転用
- **暴走防止**：目標未達・却下された案件も成功案件とまったく同じフォーマットで淡々と表示し、**「誰のせいで失敗したか」を書く欄を設けない**
- **デモ映え ★★★☆☆**

## 推し案トップ2

**1位：Petition Relay** — ①「国境」と「無血の動員力」の両方を、比喩ではなく画面上の一つの映像として同時に表現できる唯一の案。時差のバトンという発想は越境動員を支えてきた中継層（C4）の可視化そのもの ②globe.gl + Realtime + シードデータという構成は実質「リアルタイム地図アプリ」で、48時間で確実に動く。デモ映え★5が技術リスクなしで取れる希少なポジション ③**「公的窓口のみ」「目標達成で自動クローズ」は後付けのガードレールではなく、プロダクトの終わり方＝動員の終わり方を定義している。「終わらせ方を設計した動員ツール」はそれ自体が主張になる**。

**2位：Heat Guard** — ①「動員は暴走もする」に逃げずに正面から答える唯一の案。他が動員を"起こす"側なのに対しこれは"止める"側で、これが並存することでポートフォリオ全体の倫理的整合が取れる ②「集計値しか出さない＝このツール自体を晒しに使えない」という設計判断は、社会課題系ハッカソンで最も評価されやすい種類の自制であり、30秒で説明しきれる ③1位に組み込むと「加速装置とブレーキが同一プロダクトに同居する」構成になる。

## 全案共通の設計原則
**「動員の目的語を、人ではなく締切と数値に固定する」** — 標的が個人に変わった瞬間に無血の動員は私刑になる。逆に締切と目標数だけを標的にする限り、ファンダムが持つ世界最高水準の「数字を積む力」は、そのまま非暴力抵抗の技術として機能する。
